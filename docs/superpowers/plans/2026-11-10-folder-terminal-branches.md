# Folder terminal branches implementation plan

**Goal:** 逐张运行所选文件夹下游所有末端处理分支，共享上游结果。

**Architecture:** 从当前运行入口推断唯一文件夹，收集其下游所有终端及依赖。批处理计划和前端范围使用相同规则；条件循环验收后复用缓存计算末端结果，写盘节点仅在验收后执行。

**Tech Stack:** Python / FastAPI / 原生 JavaScript / unittest / node:test。

## Constraints

- 保留单节点调试与独立条件预览的范围语义；不运行无关的断开分支。
- 多保存节点分别校验输出目录，扫描时排除所有输出子目录。
- 每张图仅计算一次共享依赖；未达标不保存，逐文件错误继续策略不变。
- 结果包含末端输出，保留已有主保存节点 paths 字段兼容性。
