# Batch results and authoritative execution plan

**Goal:** 显式结果选择、禁用分支、后端唯一执行范围与逐文件/重试分层。

**Architecture:** 可选 `workflow.batch_execution` 保存 `mode`（all_terminals / selected_results）、`result_nodes`、`disabled_nodes`，缺省兼容全部末端。后端按源文件夹规划必要子图，返回执行顺序、节点角色、循环区域与结果；前端只做入口发现，使用当前请求匹配的计划渲染执行范围。逐文件状态独立记录，缓存与重试仍局限当前图片。

**Constraints:** 不改用户 JSON；单节点调试范围不变；禁用不旁路条件验收；评分结果不需要保存节点；等待或过期计划不展示旧执行范围。

- [x] 后端统一计划、每文件状态/阶段、条件验收和缓存兼容。
- [x] 前端结果/禁用控件、配置往返、计划过期隔离、服务端角色展示。

## Verified rulings

- 保留按图片延迟执行，不为整个目录一次展开子图；任务记录增加图片 ID/序号和阶段，不引入持久队列。
- 指定结果时只验收必需循环，无关未完成循环不阻塞；旧 flat 模式按所选子图校验出口。
- 循环内普通节点成为主结果后仍保留达标缓存；仅真正写盘节点排除缓存。
- 前端角色和连线依赖本次完整请求匹配的计划，乱序响应不能回填旧范围。
- 独立审查发现的达标结果重跑、无关循环提前校验、旧 flat 出口检查问题均补回归并修复。
