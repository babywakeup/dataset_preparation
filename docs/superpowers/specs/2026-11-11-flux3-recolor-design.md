# FLUX.3 三条件换色 LoRA 设计

状态：用户已确认实施（2026-11-11）；真实基础权重尚未下载。

## 目标与范围

用户选择 FLUX.3，稍后自行下载权重，并选择新增独立脚本。参考本地 Diffusers 的 `examples/dreambooth/train_dreambooth_lora_flux3_klein_img2img.py`；同目录 `test_...` 是冒烟测试而非训练入口。

学习从涂灰场景、B 色生成图和 A 色色块恢复原图 A。新增项目根目录 `train_flux3_recolor_lora.py`、`infer_flux3_recolor_lora.py`、独立 `flux3_recolor/` 支持模块及中文说明；不接入 Studio，不改原 Diffusers 示例，不自动下载权重或启动训练。

## 方案比较

- 修改原示例：复用方便，但与参考仓库耦合，用户未选择。
- 独立训练入口：用户已选择。复用原脚本的训练方法，将数据与多参考图逻辑组织为独立模块；允许必要的明确归属源码复制，避免运行时 monkey patch 原示例。
- 拼接条件为单图：会改变空间布局和推理输入约定，不采用。

## 数据合同

默认根目录 `./test`，以完整文件名配对，固定条件顺序为：`经过涂灰的原图AB`、`生成图B`、`主颜色A`；目标为 `原图A`。四目录名称集合不一致、损坏图片或场景尺寸不一致时报告文件名并失败，不静默跳过。RGB 转换及 EXIF 方向处理一致。

本轮已核实四目录各 423 个文件且名称集合相同；首个样本场景为 768×1024，色块为 32×32。其余图片的解码、尺寸和来源身份尚未全量核实。

提供不加载模型的数据检查模式，输出数量、尺寸、配对问题和拆分清单。默认固定 seed 拆出约 10% 验证集并保存清单，先按相同文件名主干分组；若发现一张源图对应多个命名不同的样本，需要显式分组映射，不能宣称仅凭名称排除了来源泄漏。训练启动拒绝空训练集或空验证集。

## 预处理与条件编码

目标与两张场景条件保持同步几何变换，初版默认保留纵横比、确定性缩放到满足模型约束的尺寸，不用随机裁剪；尺寸参数可配置，batch size 默认 1。色块独立处理，不做颜色增强。训练和推理复用相同预处理；色块最终尺寸以本地 FLUX.3 VAE/预处理的有效约束核实后确定，并记录在适配器配置中，不盲目沿用 32×32 或任意放大到场景尺寸。

三图分别经冻结 VAE 编码，按 FLUX.3 要求 patchify、归一化并展开 token，然后沿序列维拼接。对应位置编码的 L 坐标固定为 -1、-2、-3，目标图为 0；与本地 `modular_pipelines/flux3/before_denoise.py` 一致。各图允许不同 token 数，不将条件加入目标预测流。

初版可变尺寸仅允许 `train_batch_size=1`，有效 batch 通过梯度累积调整；更大单步 batch 需要后续分桶支持。多参考推理管线还会执行最多 1MP 和网格裁剪预处理，共享预处理须输出不超过预算且符合网格的图，确保再次处理不改变输入。当前默认网格为 16，32×32 色块符合网格，仍须检查实际权重 VAE 配置。

## 训练

冻结基础 Transformer、VAE 和文本编码器，仅训练 Transformer LoRA；沿用参考脚本默认的注意力/前馈目标层，覆盖 image 和 image_cond 分支。目标 latent 加噪，条件保持干净，沿用参考 flow matching 时间采样、归一化及全图 velocity loss。mask 暂不参与输入和损失。

固定默认 prompt：

> Use image 1 as the base image. Recolor the gray clothing region using the color swatch in image 3. Use image 2 as a reference for garment structure, texture, and shading. Preserve the person, pose, garment details, and background.

prompt 可通过参数覆盖，并写入输出配置。支持本地模型路径、LoRA rank、学习率、训练步数、seed、梯度累积、混合精度、梯度检查点、checkpoint 保存和恢复。默认不启用 latent 缓存；如实现缓存，必须按样本身份读取三条件及目标，不能依赖打乱后的 batch 序号。

不设未经测量的显存保证；真实分辨率和训练步数在权重及 GPU 条件明确后调整。首轮以少量样本过拟合检查条件链路，再训练完整数据。

## 验证、推理与产物

推理脚本加载本地基础权重和 LoRA，接受固定顺序的三张图或验证清单，复用训练条件预处理及默认 prompt，输出生成图。训练验证使用留出的三图条件，保存原图、条件和生成结果的可对照产物；固定 seed 比较换色色块后的响应和非编辑区域保留。

输出包括标准 LoRA safetensors、预处理/条件顺序/prompt 配置、拆分清单和恢复 checkpoint；恢复时检查数据及关键配置是否一致。默认不上传 Hub、不覆盖输入数据。
