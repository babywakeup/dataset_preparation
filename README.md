# 对象参考图 Inpainting 数据准备与 Studio

本目录用于构建对象参考图 inpainting 数据集，并提供 FastAPI + 原生 JavaScript 的 Studio 节点编辑器，支持工作流编辑、预览、保存与文件夹批处理。这里不是模型训练入口。

## 项目入口

- **CLI 数据集生成**：[启动文件](build_object_inpainting_dataset.py) → [cli.main](object_inpainting/cli.py) → [pipeline.build_dataset](object_inpainting/pipeline.py)。启动文件只是薄入口，实际逻辑在业务模块中。
- **Studio**：[启动脚本](run_object_inpainting_studio.sh)、[服务端](object_inpainting_studio/server.py)、[前端](object_inpainting_studio/static/app.js)、[循环逻辑](object_inpainting_studio/static/loop.js)。
- **使用与依赖**：[Studio 说明](object_inpainting_studio/README.md)、[中文使用指南](object_inpainting_studio/USAGE.zh-CN.md)。
- **测试**：[测试指南](tests/README.md) 提供运行命令、导入路径和浏览器测试要求。模型替代输出测试不能证明真实模型质量。

## 用持久笔记减少跨对话上下文成本

核心方法：**保存“结构 + 当前任务 + 实际状态”，不要保存整份源码或完整聊天记录。** 笔记随项目留在仓库中，新对话只读最小必要内容。

### 三层笔记

| 文档 | 作用 | 何时读取 / 更新 |
| --- | --- | --- |
| [AGENTS.md](AGENTS.md) | 简短协作入口、恢复顺序、维护约定 | 开始工作时读取；协作规则变化时更新 |
| [docs/ITERATION_NOTES.md](docs/ITERATION_NOTES.md) | 当前目标、改动、验证、阻塞、下一步 | 新对话先读“当前交接”；每轮迭代结束更新 |
| [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md) | 架构地图、模块职责、数据流、扩展点和注意事项 | 按任务只读相关章节；确认架构变化或踩坑后更新 |

不要把架构地图全文塞进每轮提示词。长期历史交给 Git，笔记只保留恢复工作需要的事实。

### 新对话如何接续

可以直接发送：

> 先阅读项目根目录的 AGENTS.md 和迭代交接中的“当前交接”，按需查阅架构地图；核对当前 Git 状态和相关源码，不要默认扫描全仓库。本次任务：……

其中“本次任务”填写具体目标、异常现象或期望结果；没有指定任务时，不应把旧摘要中的占位描述当成待开发功能。

建议恢复顺序：

1. 读取简短入口与当前交接，确认上轮做到哪里。
2. 获取本轮需求，核对 Git 差异，避免覆盖未提交工作。
3. 通过架构地图定位相关模块，只读必要源码和测试。
4. 完成修改并运行相关验证，区分文档检查、业务测试、浏览器测试和真实模型验证。
5. 更新交接，再结束本轮。

注意：笔记能提供持久上下文，但不保证所有客户端自动加载；不确定时显式要求读取。笔记也不替代源码核实。

### 迭代结束如何留笔记

可以这样要求助手：

> 请更新当前迭代交接：记录目标、改动文件与关键行为、决策理由、实际验证命令与结果、阻塞和下一步。只有新增架构事实或重要踩坑时才更新架构地图。不要复制完整日志；未执行的验证明确写“未执行”。

交接至少包含：

- **目标**：这轮要解决什么；不要只写“继续开发”。
- **改动**：涉及哪些文件、行为发生了什么变化。
- **决策与约束**：为什么这么做，哪些行为不能破坏。
- **验证证据**：实际命令、相关解释器/环境、通过/失败/跳过情况；未运行不写通过。
- **阻塞与下一步**：尚未解决的问题，以及下一轮可直接执行的动作；没有任务写“未指定”。

### 防止笔记膨胀或过期

- 优先链接到现有说明和源码，不重复抄录 API、参数表或大型代码段。
- 稳定知识放架构地图，短期状态放当前交接，不在多处维护同一份事实。
- 替换过时内容，仅保留最近几次关键迭代，不无限追加对话摘要。
- 明确区分“已验证 / 未执行 / 待确认”；历史测试通过不代表当前版本通过。
- 不记录密钥、完整日志、机器专属绝对路径；用项目相对路径和必要的环境说明。
- 需要跨机器或团队共享时，将笔记纳入版本控制；仅存在本机或聊天中的内容不等于已共享。
