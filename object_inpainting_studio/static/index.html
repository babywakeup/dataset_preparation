先从一个节点开始

下面的练习只保留一个节点，不需要理解完整流程。切换练习会替换画布，已有修改请先下载保存。

完整流程在做什么？

原图 + 物体 Mask → 检查物体 → 抠出参考图；Mask 向外扩展 → 原图对应区域涂灰；加上提示词 → 检查样本 → 导出训练数据。Mask 可以来自已有标注，也可用 SAM2 按物体框生成，或用 SAM3 按文本生成。完整示例默认仍读取已有 Mask，不运行图像生成模型。

添加节点

点击添加，拖动标题移动。点击输出圆点，再点同类型输入圆点来连接。

↻ 文件夹逐张处理单张调试

添加文件夹节点，开启「↻ 逐张」，自动标出重复执行的路径。

    Select a node to edit its input bindings.

    当前节点输出（自动识别图像 / 文本）

    点击节点的“测试此节点”查看结果。只运行它和必要的上游，不执行保存操作。

    ↻ 逐张任务 · 执行记录

    ① 在文件夹节点切换「↻ 逐张」 → ② 连到保存节点 → ③ 在画布顶部试跑或运行全部。绿色路径每张重复；琥珀色分支是固定输入，当前仍会在每轮读取。仅所选保存终点写入磁盘。

    路径、索引与执行规则

    dir 是服务器文件夹路径。recursive：0 不递归，1 递归；index 从 0 开始，试跑这一张，运行全部则从这一张到末尾。检查数量和试跑均排除输入下的输出子目录。保存目录不能是输入目录或其上级。循环上游只能包含一个文件夹节点和所选的一个保存节点；文件夹参数和保存目录须直接填写。提交后固定流程快照，编辑画布不改变已提交任务。
